# 🏠 MRS WORKS

MRS ブランドのトップページ（ポータルサイト）

このリポジトリは、MRS ブランドの作品一覧・リンク集・ポータルとして機能します。  
公開中のゲーム・ツールは、それぞれ専用の Organization リポジトリで管理しています。

---

## 🎮 公開中のゲーム（MRS-GAMES）
公開ゲームは MRS-GAMES Organization にまとめています。

- https://github.com/MRS-GAMES

各ゲームの詳細・更新履歴・公開ページへのリンクは、  
MRS-GAMES 内の個別リポジトリをご覧ください。

---

## 🔧 公開中のツール（MRS-TOOLS）
公開ツールは MRS-TOOLS Organization にまとめています。

- https://github.com/MRS-TOOLS

各ツールの詳細・更新履歴・公開ページへのリンクは、  
MRS-TOOLS 内の個別リポジトリをご覧ください。

---

## 🛠 開発方針
- 開発中のゲーム・ツールは **個人アカウント（masashi-dev）** の単独リポジトリで管理
- 安定したら **MRS-GAMES / MRS-TOOLS** に移動して公開
- 公開後の修正は Organization 内で行う
- MRS WORKS はブランドのトップページとして、基本的に大きな変更は行わない

---

## 🌐 公開ページ
MRS ブランドの公開ページはこちら：

- https://mrs-works.pages.dev/  
（Cloudflare Pages にて公開中）

---

## 📁 このリポジトリについて
MRS WORKS は “公開棚” ではなく、  
**MRS ブランド全体のホームページ** として運用しています。

そのため、ゲームやツールのコードは含まず、  
リンク・紹介・ブランド構成の整理を目的としています。
