## ホーム画面への追加・オフライン表示

- iPhone / Safariでは共有メニューから「ホーム画面に追加」で利用できます。
- 名称は「MRS WORKS」。`assets/mrs-works-logo.png` が採用した文字入りロゴの原本で、`assets/icons/` に用途別サイズを収録しています。形や文字は変更せず縮小し、maskable版のみ黒い余白を追加しています。
- 初回はオンラインで必要ファイルを取得します。取得後はホームとプライバシーポリシーをオフライン表示できます。各アプリ・お問い合わせ先の通信やオフライン対応は、それぞれのサイトに依存します。
- 静的ファイルはリリース単位で事前取得しキャッシュ優先で表示します。広告・外部解析・解析POSTはキャッシュ対象外で、送信のオフライン待ち行列も追加しません。広告は独立したiframeで読み込み、本体の初期化を待たせません。
- 更新は全対象ファイルの取得成功後、旧版の全タブ・ホーム画面ウィンドウを閉じた後に適用します。`skipWaiting()` と `clients.claim()` は使用しません。
- キャッシュ対象を変更したら、`service-worker.js` の `RELEASE` と `FILES` を更新してください。削除するのは `mrs-works-home:<設置パス>:` で始まる旧キャッシュのみです。localStorageや他アプリのキャッシュには触れません。
- キャッシュ欠損時の通信は4秒で打ち切り、HTMLでは再読み込み案内を出します。初めての完全オフライン起動は対象外です。
- 確認項目：初回取得、通常・弱回線・オフライン再読み込み、クエリ付き入口、`privacy` / `privacy.html`、更新待機と更新失敗、保存データ維持。実機iPhone / Safariとホーム画面起動はプレビューで別途確認してください。

## 🛠 開発方針
- 開発中のゲーム・ツールは **個人アカウント（masashi-dev）** の単独リポジトリで管理
- 安定したら **MRS-GAMES / MRS-TOOLS** に移動して公開
- 公開後の修正は Organization 内で行う
- MRS WORKS はブランドのトップページとして、基本的に大きな変更は行わない

## 📁 このリポジトリについて
MRS WORKS は “公開棚” ではなく、

リンク・紹介・ブランド構成の整理を目的としています。
